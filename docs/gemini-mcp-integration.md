# Integrating HRM Remote MCP with Gemini Spark

This document outlines how to connect Google's Gemini Spark to the HRM Remote MCP server using the newly implemented OAuth 2.0 flow. This ensures that when Gemini queries the HRM system, it does so using the specific roles and permissions of the HRM user who authorized the connection.

---

## 1. Architecture Overview

The integration uses an OAuth 2.0 Authorization Code flow with PKCE, allowing Gemini to authenticate on behalf of specific HRM users:

```text
                    Gemini Spark
                         │
                         │ (OAuth 2.0 Authorization Code Flow)
                         ▼
                  HRM Laravel App
                         │
        (User logs in and approves consent)
                         │
                         ▼
                   OAuth Token
                         │
                         ▼
                  AuthenticateRemoteMcp Middleware
                         │
                         ▼
                   Laravel User
                         │
       (Evaluated against standard Laravel RBAC)
                         │
                         ▼
                    Execute MCP Tool
```

---

## 2. Setting Up the Custom Connected App in Gemini

Administrators or individual users must configure the HRM Custom App within the Gemini Spark UI to establish the connection.

### Automatic Configuration (Recommended)
Our HRM system exposes a `.well-known/oauth-protected-resource` and `.well-known/oauth-authorization-server` endpoint. In many cases, Gemini can auto-discover the required OAuth endpoints if you provide the server's root URL:
- **Server URL:** `https://kirikaadigital.com`

### Manual Configuration
If Gemini requires manual entry for the Custom App settings, use the following:
- **Issuer / Server URL:** `https://kirikaadigital.com`
- **Authorization Endpoint:** `https://kirikaadigital.com/oauth/authorize`
- **Token Endpoint:** `https://kirikaadigital.com/oauth/token`
- **Client ID:** *(Generated by Gemini or provided by your HRM administrator)*
- **Client Secret:** *(Leave blank for public PKCE clients)*
- **Scopes:** `mcp` (or leave empty if no additional scopes are required by Gemini)

---

## 3. Connection and Authorization Flow

Once the app is configured in Gemini, users can connect their accounts:

1. **Initiate:** In Gemini, select the HRM Custom App and click **Connect**.
2. **Redirect:** Gemini will redirect your browser to the HRM login page at `https://kirikaadigital.com/oauth/authorize`.
3. **Log In:** Enter your HRM credentials (Email/Username and Password).
4. **Consent:** You will see an Authorization Screen asking you to approve Gemini Spark's access to your account.
5. **Approve:** Click **Approve**.
6. **Return to Gemini:** You will be redirected back to Gemini, and the connection will be established.

---

## 4. Usage and Role-Based Access Control (RBAC)

Once connected, you can converse with Gemini and ask it to query or modify data in the HRM system. 

**Important:** The system strictly enforces your specific permissions!

* **HR Admins:** Can ask Gemini to perform administrative tasks, such as generating organization-wide payroll reports, updating company policies, or managing projects.
* **Standard Employees:** Can ask Gemini to check their own leave balance, view their own shift schedule, or request time off. If a standard employee asks Gemini to "delete a project" or "view another user's salary," the HRM server will return a `403 Forbidden` error, and Gemini will inform you that you lack the necessary permissions.

---

## 5. Troubleshooting

* **401 Unauthorized / Invalid Client:** This occurs if the Client ID entered in Gemini is incorrect or missing from the HRM database. Ensure the client is properly registered in Laravel Passport.
* **500 Server Error on Connect:** Ensure the latest codebase (specifically `resources/views/passport/authorize.blade.php` and `AppServiceProvider.php`) is successfully deployed to your production environment.
* **Tools Not Showing Up:** Ensure the HRM Remote MCP server URL (`https://kirikaadigital.com/mcp`) is correctly specified in Gemini.
